# Huddle releases

Installers and auto-update files for **Huddle**, a desktop app for group chat, voice rooms and screen sharing.

- **New here?** Download `Huddle_*_x64-setup.exe` from the [latest release](https://github.com/WestFRM441/huddle-releases/releases/latest) and run it. Windows may say "Windows protected your PC" because the app is not code-signed yet; choose **More info → Run anyway**.
- **Already installed?** Huddle updates itself — you will see an "Update and restart" prompt.

This repository only holds release files, not source code. Updates are signed; the app refuses any update not signed with the Huddle release key.
